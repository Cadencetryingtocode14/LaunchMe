# LaunchMe

## Project Title
**LaunchMe: Luxury Space Travel Agency**

---

## Project Option
**Responsive Website**

---

## Project Description
LaunchMe is a fictional luxury space travel agency that allows users to browse imaginative vacation destinations beyond Earth. Visitors can explore unique trips, view destination details through interactive flip cards, and complete a simulated booking experience. The website combines modern web design with interactive elements to create the feeling of browsing a premium travel agency.

---

## Theme Interpretation
LaunchMe interprets the theme of **Space** by imagining the future of luxury space tourism. Rather than focusing on exploration or survival, the project presents outer space as a destination for leisure and adventure. Users experience a fictional travel website that encourages them to imagine vacations on planets, comets, and orbital resorts.

---

## Intended User
This website is designed for anyone interested in science fiction, creative storytelling, space exploration, and interactive web experiences.

---

## User Goal
Users are encouraged to:

- Browse available destinations
- Compare unique travel experiences
- View trip details
- Book their favorite destination
- Complete the simulated booking process

---

## Responsive Design

The website is responsive using CSS Grid, Flexbox, and media queries. Content automatically adjusts for desktop, tablet, and mobile devices by reorganizing layouts, resizing images, and stacking navigation elements when needed.

---

## User Testing

Classmates tested the website on desktop browsers and by resizing the browser window. Feedback showed that users immediately understood the concept and enjoyed the destination card interaction. Suggestions included making clickable elements more obvious, improving destination content, and strengthening the luxury travel aesthetic.

---

## Revisions

Following user testing, the project was updated by:

- Replacing placeholder destinations with original locations and descriptions
- Improving the booking flow so users browse destinations before booking
- Adding a booking confirmation page
- Creating a promotional countdown popup
- Improving typography, spacing, and overall branding
- Refining the responsive layout
